Local Setup Guide

Get Up and Running in 3 Minutes

Clone the repository and launch the onboarding wizard on your local machine.

bash — terminal Prerequisites: PHP >= 8.3, Composer, Node.js (^20.19.0 || >=22.12.0)
1. Clone the repository:
git clone https://github.com/DyanGalih/beressuite.git
cd beressuite
2. Install dependencies & build frontend assets:
composer install
npm install && npm run build
3. Configure environment and serve:
cp .env.example .env
php artisan key:generate
# If planning to select SQLite: touch database/database.sqlite
php artisan serve
🎉 Launch Wizard: Open http://127.0.0.1:8000 in your browser. The onboarding wizard will verify server requirements, test your database, and guide you through creating your initial administrator account.
